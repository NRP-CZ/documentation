---
title: National Repository Platform Infrastructure
---

The data centers operated for the NRP are based on object storage technology utilizing Ceph and applications are run in Kubernetes containers. These data centers are located exclusively within the Czech Republic, meaning all your data remains within the country. The distributed model of data storage and service provisioning enhances data redundancy through the use of geographical replicas. This approach ensures that data in the NRP can withstand media failures, and even significant damage to one of the geographical locations.

On the infrastructure level, the platform provides the following services
ready to be used by all the repositories:

* Ceph - distributed storage system with support for replication and digital integrity, including support for S3 APIs
* Kubernetes - container orchestration platform where repositories and infrastructure services are deployed
* e-INFRA CZ AAI - authentication and authorization infrastructure for the platform
* Opensearch - search engine for metadata and full-text search
* Postgres - relational database for storing metadata and other structured data
* Fixity service - service for checking the integrity of digital objects
* IIIF Server - server for serving images in the IIIF format
* Monitoring services - monitoring of the infrastructure and services
* Issue tracking - issue tracking for the platform
* Documentation services - documentation for the platform
