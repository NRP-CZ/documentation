- **Nový datový catch-all repozitář bude od pondělí 22. 6. na adrese [https://datarepo.eosc.cz](https://datarepo.eosc.cz). Aktualizujte si své záložky.**

## New data catch-all repository coming soon

- **The new data catch-all repository will be available from Monday, June 22 at [https://datarepo.eosc.cz](https://datarepo.eosc.cz). Please update your bookmarks.**
- We are just transferring data to a new cluster, therefore login and adding new records is currently suspended. We apologize.
- **[Browsing and downloading records (without login) still
  works](https://data.narodni-repozitar.cz).**


---

## What will change?

- New features (such as record versioning), new look&feel, a long list of tiny changes under the hood.

- Access to the repository and communities will be set up in the virtual organization „Datový catch-all repozitář“ (`VO_repo_datarepo_prod`). Because the repository will be registered as an infrastructure service, for formal reasons (GDPR, operating rules, etc.) it is necessary to re-register for the repository. Users who have communities in the repository or have deposited records into it will be sent a pre-approved invitation that only needs to be confirmed. Other users will be able to register when accessing the repository.

- The repository will be newly available at https://datarepo.eosc.cz and will have a new visual appearance. The current address data.narodni-repozitar.cz will be discontinued.

- User support will be directly available at datarepo@eosc.cz (no need to remember, it will be in the footer of the repository website). Regardless of the NRP repository and service, you can always write to support@eosc.cz, where your request will be forwarded to the right place.

- Don't worry about DOI's, we will redirect them to the new repository. Published records from the old repository will be transferred to the new one by us. Authors of unfinished records have been contacted by e-mail.
