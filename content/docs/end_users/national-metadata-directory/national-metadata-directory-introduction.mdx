---
title: National Metadata Directory
---

[National Metadata Directory (NMD, Národní metadatový adresář/NMA in
Czech)](https://nma.eosc.cz/) is a metadata aggregator for datasets in
repositories operated in the [National Repository
Platform](../../intro-to-nrp/intro-to-nrp) and
beyond.

## Mission

The NMD aggregates (harvests) metadata from all repositories operated in
the National Repository Platform and from other repositories that contain
datasets produced by Czech academic community.

Its primary purpose is to allow basic searching throughout the
repositories, locating datasets of interest for the user. Searching is
performed using basic metadata and the NMD contains links to primary
repositories.

The NMD does not collect the data, just its metadata records.
Note that the linked primary repository may support searching using richer set of
metadata fields, and may have specialised functions depending on the
metadata that make searching easier to use and more specific.

## Using the NMD

The metadata in the NMD is publicly available. There is no need to register
nor log in just to browse the records.

Browse to [the web interface of the NMD](https://nma.eosc.cz/).

You can either use the search bar to type in keywords of interest.

Or, by clicking on **Show all records**, you open a browser that supports
listing the records, and filtering them using various parameters.

Listing of an individual record is rather intuitive, the link “Original
record” points to the source repository that keeps the original data record
itself.

## Creating Metadata Records in the NMD

Since 2026, having a metadata record in the NMD is mandatory for datasets
collected to [IS VaVaI/RIV](https://www.isvavai.cz/riv). Ideally, the repositories containing primary
datasets should be harvested by the NMD. If it is not the case for your
dataset, you can obtain write access to the NMD and create the metadata
record manually. [Start with obtaining access to the NMD if you need a link
to your dataset metadata](national-metadata-directory-access).
