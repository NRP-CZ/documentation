---
title: National Metadata Directory Roadmap
---

Last updated: Nov 3, 2026


**End of October 2026**

- Support for CCMM 1.1

- Metadata from NMD is harvested to OpenAIRE


**End of November 2026**

- Assignment of harvest administrators, registration of new CCMM1.1/Datacite OAI harvest sources.

- CCMM 2.0 supported via [XSLT transformation from CCMM 2.0 to CCMM 1.1](https://github.com/techlib/CCMM-utils/tree/main/version-transformation) published and supported by NTK as a temporary precaution until CCMM 2.0 is implemented. CCMM transformations 2.0 -> 1.1 and 1.1 -> 2.0 are both lossy! 

- NMD preparation for the next reporting period, import of current data from IS VaVaI, ROR, and ORCID.


**December 1st 2026**

- Freezing of the NMD codebase, no more code changes until July 2027. This includes code changes necessary for accommodating new OAI-PMH endpoints of repositories wishing to be harvested to NMD. Including harvests from repositories exporting valid CCMM will be possible any time, CCMM validator will be available.


**Summer 2027**

- Native support for CCMM 2.0
