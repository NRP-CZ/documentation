---
title: Obtaining Write Access to the National Metadata Directory
---

While majority of metadata records should be automatically harvested to the
National Metadata Directory (NMA), it may be necessary to create a metadata
record manually.

This document describes how to:
- get access to the NMA,
- create a metadat record in the NMA.

Note that getting user access to the NMA is necessary only for manual
creation of records there. It is not needed just to browse and/or search
records.

## Getting User Account in the NMA

Anybody can get a user account in the NMA. If you are affiliated with an
academic institution in the Czech Republic (e.g. a university student or
employee, AS ČR employee, ...), an automatic registration is all you need.
Otherwise, your application will be decided upon automatically.

Browse to https://nma.eosc.cz. Select Log in.

## Logging in to the NMA

After obtaining the user account, you can log into the NMA, using the Log
in button. Similar to the registration process, select your institution
from the list (or the social network identity used previously). Your
browser will likely remember the previously selected organisation.

## Creating a Metadata Record in the NMA

You need to be logged in the NMA to be able to create metadata records of
your datasets.

Start by selecting „Create record“.

In case your dataset is assigned a DOI issued by DataCite, you should be
able to harvest necessary metadata from DataCite. Otherwise, the metadata
can always be filled in manually.
