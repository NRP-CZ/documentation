## Public pilot
This is the landing page for the public pilot project connecting the NRP and e-INFRA.CZ computing environments. Please feel free to try out the solutions and components, and provide us with feedback. Thank you in advance.

Not all anticipated services and their combinations are currently supported. The document below, called Target Architecture, describes what we plan to support.

## Workflow engines
- Galaxy - [public pilot instance](https://usegalaxy.cz/) + documentation and sample workflow (with INVENIO pilot catch-all repository)
- Lexis - [public pilot instance](https://docs.lexis.tech/) + [documentation and sample workflow](https://opencode.it4i.eu/lexis-platform/data/api-v2/-/tree/dspace) (with [dSpace pilot catch-all repository](https://dspace-dev.ufal.mff.cuni.cz/home)).
## CLI based environments and Jupyter Notebooks
- [MetaCentrum docs](https://docs.metacentrum.cz/en/docs/data/types-of-storage#national-repository-platform-nrp) (Grid, cloud, kubernetes, Jupyter notebooks, currently INVENIO only)
