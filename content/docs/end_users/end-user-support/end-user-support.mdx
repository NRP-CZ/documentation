This document describes how user support is provided within the National Repository Platform (NRP) project. It is intended as an overview of basic procedures for users who wish to use NRP services or services provided within EOSC CZ.

Support for individual services is primarily provided by the service managers, who have the most detailed knowledge of the specific solutions. The Service Desk (operated by the CESNET association) serves as the primary point of contact for recording, routing, and resolving user requests.

## Main Point of Contact for User Support

The main point of contact for user support is the Service Desk (operated by the CESNET association). The Service Desk is available 24/7.

### Contact Information
* **E-mail:** [support@eosc.cz](mailto:support@eosc.cz)
* **Phone:** +420 234 680 222
* **Contact form:** [User support contact form](https://www.eosc.cz/en/services/all)
* **Operating hours:** 24/7

### How does the Service Desk work?
After receiving a request, the Service Desk:
1. Registers the request.
2. Assesses the nature of the request.
3. Will attempt to resolve it directly.
4. If it is outside their scope of responsibility, will forward it to the appropriate service administrator or repository manager.

## Basic User Scenarios

The following scenarios describe how the User Support percieves its roles
in various use cases of the NRP, including suitable communication channels
for each particular case.


### Scenario 1: I want to deposit data in a repository

**How do I find a suitable repository?**
Search for a suitable repository via the [NKR](https://repo.cz/#urls/objects/design?payload=about.html). Take into account any internal rules of your home institution which may specify where research data should be deposited.

**Do I need advice on data submission?**
Before submitting data, we recommend reviewing the user documentation and the repository policy,
which outline the basic rules, including the repository’s licensing agreement. The documentation
typically includes: supported formats, best practices, metadata requirements, rules for accessing
submitted data, and more.

**Where or who should I contact?**
* Contact the administrator of the specific repository.
* If in doubt, contact the Service Desk via email at [support@eosc.cz](mailto:support@eosc.cz).

### Scenario 2: I want to find data in a repository

**How do I find an existing repository?**
Use the NKR, which contains a list of available repositories, their focus, and contact details for administrators.

**How do I find data?**
Search through the [National Metadata Directory](https://nma.eosc.cz) for datasets.
If you're unsure and haven't found the information you're looking for, we recommend first reviewing
the [user documentation](https://docs.nrp.eosc.cz/en/docs/end_users/end_users).

**Where or who can I contact?**
If you cannot find what you are looking for, you can:
* Contact the administrator of the specific repository.
* If in doubt, contact the Service Desk via email at [support@eosc.cz](mailto:support@eosc.cz).
