This is the technical documentation of the National Repository Platform (NRP), built and operated for scientific data in the Czech Republic.

It contains mainly:

- [**NRP Introduction**](intro-to-nrp/intro-to-nrp) — what the NRP is and how it works

- [**For End Users**](end_users/end_users) — working with records in a repository

- [**For Repository Administrators**](repo_admins/repo_admins) — building, running and operating a repository

As the NRP is a complex system with services operated by several institutions, extensive parts of the documentation are linked from here.
