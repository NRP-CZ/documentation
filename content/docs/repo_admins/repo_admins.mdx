This section of the site collects documentation relevant for repository
administrators, e.g.
- technical documentation of repository implementations,
- technical documentation for operators of specific services in the infrastructure,
- links to specialised documentation of particular tools, howtos, and
  policies,
- hints for user support.

If you are just an end-user of a repository, this section is definitely not
for you, we have a [documentation for end/users as well](../end_users/end_users).

This documentation is intended for repository administrators, operators of
services in the NRP, and software developers. It is a reference and a
collection of links to detailed resources than a guide. 

If you intend to establish a repository or to operate a
repository-related service in the NRP, we strongly suggest starting at
[the guide to create a new repository in the NRP](https://www.eosc.cz/en/services/data-storage/repositories-in-nrp/creating-repositories-in-the-nrp). The documents listed there will give you an easy-to-digest introduction and you will be helped by our staff in the process. You can always come back here for reference and details.
