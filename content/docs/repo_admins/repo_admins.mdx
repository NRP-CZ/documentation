## Overview

This section of the site collects documentation relevant for repository
administrators, e.g.
- technical documentation of repository implementations,
- technical documentation for operators and support staff of specific repositories and services in the infrastructure,
- links to specialised documentation of particular tools, how-tos, and
  policies,
- hints for user support,
- frequently asked questions.

Use the navigation in the Table of Contents.

## Scope of this Documentation

This documentation is intended for repository administrators, operators of
services in the NRP, and software developers. It is a reference and a
collection of links to detailed resources than a guide. 

If you intend to establish a repository or to operate a
repository-related service in the NRP, we strongly suggest starting at
[the guide to create a new repository in the NRP](https://www.eosc.cz/en/services/data-storage/repositories-in-nrp/creating-repositories-in-the-nrp). 
The documents listed there will give you an easy-to-digest introduction 
and you will be helped by our staff in the process. You can always come back here for reference and details.
