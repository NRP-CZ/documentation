## Virtual Organisation Membership

Access to the NMD is controlled by `VO_repo_nma_prod'. End users become
members of the VO, members can directly login into https://nma.eosc.cz.

Signing up is handled the same way as logging in; when the user is not in
the group, the user is redirected to a registration. Users eligible to use
e-infrastructure services are approved automatically, other users may be
approved manually.

Manual approval: VO VO_repo_nma_prod -> applications -> select and
approve/reject. A warning that a user is not eligible to e-infra services
will be displayed during the process.
