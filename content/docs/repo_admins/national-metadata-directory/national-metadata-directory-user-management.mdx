## Virtual Organisation Membership

Access to the NMD is controlled by `VO_repo_nma_prod' controlled by https://perun.e-infra.cz.

End users of the NMD become
members of the VO, i.e. members of `VO_repo_nma_prod' can directly login into https://nma.eosc.cz. Note that subgroups of this VO are used to control access to infrastructure services.

Signing up of end users is handled the same way as logging in; when the
user is not in the group, the user is redirected to a registration. Users
eligible to use e-infrastructure services are approved automatically, other
users may be approved manually.

Manual approval: VO VO_repo_nma_prod -> applications -> select and
approve/reject. A warning that a user is not eligible to e-infra services
will be displayed during the process.
