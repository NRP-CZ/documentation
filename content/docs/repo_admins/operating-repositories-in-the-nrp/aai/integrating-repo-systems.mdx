---
title: Integrating a repository system with AAI
---

Integration of a repository system heavily depends on the system itself.
A wide scale of options is available, for basic management of identities to
offloading group membership management into the AAI completely.

If you choose one of the core NRP repository systems, most of the
infrastructure groundwork has already been done for you:
- CESNET-Invenio instances accept identities from EOSC AAI (through ProxyIdP) and stores all group membership information into Perun, in addition to that, common operations on groups are implemented in CESNET-Invenio itself (with the goal the end user should never need to use Perun directly),
- CLARIN-DSpace and ASEP/ARL instances accept identities from EOSC AAI,
  group membership is kept in the instances,
- alternative repository implementations and other services are required at
  least to accept identities from EOSC AAI.

For all repositories and services operated in the NRP (fully or partially),
there is a virtual organisation set up to keep records of personnel and
service identities to operate each particular instance. We strongly
recommend adhering to [virtual-organisation-setup](group naming
conventions) to make support much easier.

AAI setup should be done after a consultation with repository system
specialists who may refer you to AAI specialists when necessary.

# Generic checklist for integrating the repository with AAI

Full checklist for integrating a service into NRP AAI follows. It is only
relevant for you if you integrate a third party service. If it not your
situation, it is just a jump scare for you.

- Register the repository in the [AAI Service Registry](https://spadmin.e-infra.cz/auth/requests/new)
- Create a virtual organization and facility records for the repository in the [AAI Admin GUI](https://perun.e-infra.cz/)
- Customize the group structure, registration process and email notifications in the [AAI Admin GUI](https://perun.e-infra.cz/)
- Set up the resource structure and cross-link it with the group structure in the [AAI Admin GUI](https://perun.e-infra.cz/)
- Configure or implement integration of non-standard access control capabilities, if any

Note repository integration with AAI must be tested before it is enabled for use in production environment.
