# Description of the basic Catch-all Data Repository dashboard and record creation 
In this guide you can find elementary description of Catch-all Data Repository dashboard and the step-by-step process on how to create your record in the catch-all data repository.

## Elementary functions after logging in

Unauthenticated user can browse all public records in the catch-all data repository by default. Just click on **BROWSE ALL RECORDS /1/**. If you wish to create new record you have to log in via **LOG IN /2/** button. 

<Callout type="warning" emoji="⚠️">
To be able to log in you need to register into virtual organization **[VO_nr](catch-all-repository-introduction.mdx#register-to-access-and-create-your-very-first-record)**.
</Callout>

![new-record](/img/nrp/catch-all-data-repository/data-repo1.png)

Once you logged in you can **Upload /1/** new data and create new record or you can **BROWSE ALL RECORDS /2/**.

![new-record](/img/nrp/catch-all-data-repository/data-repo2.png) 

<br/>

<Callout type="warning" emoji="⚠️">
If you click on **BROWSE ALL RECORDS /2/** you can see all public records. To see your drafts you have to **select the community /1/** where you drafted your record. That is the reason why the number of **results /2/** with or without the selected community can be different.
</Callout>

<br/>

![new-record](/img/nrp/catch-all-data-repository/data-repo3.png)

<Callout type="info" emoji="ℹ️">
**About communities** <br/>
Communities in catch-all data repository serve as the namespace for individual research groups/institutions. If you wish to use catch-all repository for your laboratory/research group you can consider a community as a group of users. This solution is suitable for larger groups of users. You can manage users who will potentially be in your community using the Perun (user management system). It is also possible to distribute specific rights in the group, e.g. members can only create records while others roles are able to check and approve the records and request publication from the curators/publishers. It is also possible to share records and datasets privately only within the selected community.
</Callout>

## Creation of new record
Below you can find the guide on how to create new record in catch-all data repository.

<Callout type="warning" emoji="⚠️">
To be able to log in you need to register into virtual organization **[VO_nr](catch-all-repository-introduction.mdx#register-to-access-and-create-your-very-first-record)**.
</Callout>

1. Please log in to the [catch-all repository](https://data.narodni-repozitar.cz/) using you institutional identity.

2. Then click on **Upload** button.

3. Then you can start to fill in the insert form.

	a) The form is divided into multiple sections.
	b) The starred fields are mandatory, if do not fill them you cannot save the draft.
	c) In some fields is necessary to select the value from the dictionary, in case you cannot find desired value, please contact the [catch-all data repository support](catch-all-repository-introduction.mdx#general-information).
	d) Some fields have their own context help.
	e) Access to the datasets is controlled via the **Date availabe** setup, see [access control section](catch-all-repository-access-control#access-embargo-for-published-records).

4. If you filled in all data fields and there are no errors you can save a draft. Error fields are denoted with red colour.

5. Attach the data/files
	
	a) The formats of the data/files are not limitted.
	b) Maximal size of the data/files is limitted up to **500 GB**.
	c) You can add description to the data/files (pencil icon under the file name).

6. Finish the upload by clicking on the green button **Upload file**.

7. Once you finish with inserting you can check your data set.
