# National Data Repository: Introduction

The National Data Catch-all Repository is a repository for general scientific data.

## Mission

The repository is intended for general scientific data, for which no better
deposition option exists. While the catch-all repository is handled with
all the care needed to operate a repository, users are advised to
- prefer using an established topical repository is available for their
  data in their scientific discipline,
- get familiar with their scientific community standards and customs in
  their particular field of study.

During the build-up phase of the National repository platform, the
catch-all repository is used by some research groups as a temporary
solution before their specific repository is established.

Specific community repositories will usually provide better findability of
the data and have specific metadata models tailored for the needs of
particular communities. The catch-all repository supports a generic
metadata model covering basic needs. It supports assigning persistent
identifiers (DOI).

Data deposition is available to users who registered to the service.
Data deposition workflow (FIXME link) consists of preparing the records by
the user. The records (mainly their metadata) are then checked by the
curators, finalised, and published.

Published data is accessible to the public internet (without any
authentication).

After the record is finalised, neither its data nor metadata can be changed
any longer.

Data deletion is handled upon user request by the curators. For the time
being, there is no data life cycle policy yet.

User support is available through nr-support@cesnet.cz.
