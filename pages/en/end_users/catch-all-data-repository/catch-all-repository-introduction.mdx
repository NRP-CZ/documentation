# Catch-all National Data Repository: Introduction

The Catch-all National Data Repository is a repository for general scientific data.

## Mission

The repository is intended for general scientific data that should be
stored into a repository, but for which no better
deposition option exists. While the catch-all repository is handled with
all the care needed to operate a repository, users are advised to
- prefer using an established topical repository is available for their
  data in their scientific discipline,
- get familiar with their scientific community standards and customs in
  their particular field of study.

During the build-up phase of the National repository platform, the
catch-all repository is used by some research groups as a temporary
solution before their specific repository is established.

Specific community repositories will usually provide better findability of
the data and have specific metadata models tailored for the needs of
particular communities. The catch-all repository supports a generic
metadata model covering basic needs. It supports [assigning persistent
identifiers (DOI)](https://www.doi.org/).

The records in the repository are published by default. An embargo period
may be set: data of embargoed records are kept private and after the period
elapses, the record is automatically published in full.

## General Information

The National Data Catch-all Repository is operated by CESNET in scope of
the NRP project.

The records are curated by the National Library of Technology.

Data deposition is available to users who registered to the service.

There are no restriction on file formats.

Published data is accessible to the public internet (without any
user authentication).

After the record is finalised, neither its data nor metadata can be changed
any longer.

Data deletion is handled upon user request by the curators. For the time
being, there is no data life cycle policy yet. Note that it is the policy
of organisations assigning persistent identifiers (e.g. DOI) that at least
a basic metadata record of a dataset must be preserved forever, even if the
data itself is deleted.

User support is available through nr-support@cesnet.cz.

## User Registration

Write access to the repository is available to members of virtual organization **VO_nr**. To apply:

1. You need to submit the **[VO_nr application](https://einfra.cesnet.cz/allfed/registrar/?vo=VO_nr)**.

2. Once your application is approved you will receive a mail notification.

3. Then you can continue to **[Catch-all data repository](https://data.narodni-repozitar.cz/)** and log in, which gives you permissions to **[create your first dataset](catch-all-repository-record-creation.mdx)**.
